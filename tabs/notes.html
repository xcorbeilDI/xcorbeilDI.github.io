Tester les notifications web

Un site HTTPS est necessaire pour les tests Web Push.

  • Le site doit contenir le fichier DI.WebPush-sw.js.
  • Pour activer les logs de diagnostique, ajoutez ?ofsysDebug=1 dans l'URL.
  • GitHub Pages est une option simple pour heberger un site HTTPS de test.
  • Verifier les scenarios: Identify, Reset, token fr et token en.
